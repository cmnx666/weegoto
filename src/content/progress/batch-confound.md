> **2026-10-19 复核说明：** 本文保留 2026-10-08 的历史实验记录，不作为当前唯一基线。现存结果文件中，不同预处理与特征配置的指标存在差异；请以[资源页的结果来源表](/resources/#results)核对配置。下文的历史 AUC 与置换 p 值不可跨版本拼接。

## 先说结论

历史记录中，模型在 62 名被试上报告 **88.7% 准确率、AUC 0.950**。

但一个**完全不看脑电数据**、只使用"这段录音是哪天录的"的模型，就能达到 **AUC 0.892**。

不能用两个 AUC 的差值量化批次的因果贡献。当前这个准确率**无法排除"模型学到的是采集批次差异，而不是抑郁病理"**。

## 事情是怎么被发现的

最初我们只是想核对一下数据完整性。解析 181 个 EDF 文件的头部字段时，注意到记录标识里带着采集日期，于是顺手统计了一下两组的时间分布：

| 采集月份 | HC | MDD |
|---|---|---|
| 2011-07 | 5 | 0 |
| 2011-08 | 14 | 0 |
| 2013-01 | 53 | 0 |
| 2013-04 | 2 | 15 |
| 2013-05 | 3 | 38 |
| 2013-06 | 3 | 19 |
| 2013-07 | 6 | 23 |
| **合计** | **86** | **95** |

健康对照集中在 2011 年夏天和 2013 年 1 月，患者集中在 2013 年 4–7 月。
全部 42 个采集日里，**只有 2 天两组都有数据，且合计只有 5 个 HC 文件和 5 个 MDD 文件**。

也就是说，"组别"和"采集批次"在这份数据里**几乎完全共线**。

## 三个对照实验

为了量化这个问题的严重程度，我们做了三组实验。

### 对照一：只用采集时间戳

把每个被试最早一次采集的时间戳当作唯一特征，跑同样的 5 折交叉验证：

| 输入 | 交叉验证 AUC |
|---|---|
| **仅采集时间戳** | **0.892** |
| 采集时间 + 性别 | 0.885 |
| 仅性别 | 0.484 |
| 随机猜测 | 0.500 |

### 对照二：只用 1 个全局幅度标量

把"全体通道、全体频带的平均功率"压成**一个数字**，作为唯一特征：

- 被试级准确率 **77.4%**
- AUC **0.817**

该标量来自 EEG，并非“不看脑电”。与多维特征的差异不能直接解释为各因素的独立因果贡献。

### 对照三：抹掉整体幅度

把每个片段的 95 维特征减去自己的均值（等价于除以几何平均功率），彻底删掉"整体信号大小"这个信息：

- AUC 仍有 **0.948**

这提示去除整体幅度后仍存在可预测标签的模式，但该模式也可能包含批次差异，不能据此确认病理来源。

## 检查过哪些其他因素

| 检查项 | 结果 | 结论 |
|---|---|---|
| 采集时长差异 | 仅用片段数预测组别 AUC 0.460 | 该对照预测能力较低，不能排除所有时长影响 |
| 文件大小差异 | AUC 0.392 | 该对照预测能力较低 |
| 设备是否不同 | 两组用的是同一台设备（序列号一致） | 头部序列号一致，不排除设置与校准差异 |
| 标签是否错标 | 跨组别波形重复 0 对 | 未发现该类跨组重复，不等于排除所有错标 |
| 是否只是碰运气 | 置换检验 p = 0.0099 | 该决策分数流程的标签关联检验；不是诊断效度证明 |
| 是否伪迹造成 | 完整做 ICA 去伪迹后，基线 AUC 反而略升 | 不足以排除残留伪迹或清洗差异 |

## 诚实的结论

> 模型学到的信号是**真实存在**的，其中既包含可能与抑郁相关的脑电模式，也包含了**无法与采集批次分离的技术差异**。
>
> 在当前数据设计与有限的批次重叠下，**难以可靠分离这两类因素**。需要补充批次内对照与独立外部数据，不能把统计校正视为自动消除混杂。

这是需要优先处理的**数据设计与评估问题**，同时仍需持续核对代码和结果版本。

## 下一步

1. 向数据方索取批次元数据（设备增益、电极批次、操作人员、被试人口学与量表）
2. 先核对各批次的类别与独立被试数量；条件允许时开展留批次评估。批次校正须在训练折拟合，并报告适用假设与失败条件
3. 在批次问题受控之前，**不把准确率解释为诊断能力**

我们把这件事写出来，是因为它比多报几个百分点的准确率重要得多。
