## 阅读目标与来源

这是一份学习预习报告，不是项目实验结果。适合已经学过矩阵乘法、反向传播、卷积和基础神经网络的同学。建议分两次阅读：先理解“模型怎样使用过去”，再手算递推和扫描。文中的算例、练习与 EEG 方案是为项目组编写的教学材料，不代表已经完成相应实验。

阅读主线来自 Maarten Grootendorst 的 [A Visual Guide to Mamba and State Space Models](https://www.maartengrootendorst.com/blog/mamba/)（2024-02-21）。该指南依次讨论注意力的成本、循环状态、连续与离散 SSM、递推与卷积、HiPPO、选择机制、并行扫描、硬件优化和 Mamba block。本报告采用独立讲解，不转载原文插图；技术细节以文末原始论文为核对依据。范围是原始 Mamba（常称 Mamba-1），不把后续变体混在一起。

## 1. 先把任务和张量认清楚

序列建模的输入可以写成 X，形状为 `(B, L, D)`：B 是批量大小，L 是序列长度，D 是每个位置的特征维度。文本的一个位置是 token；EEG 的一个位置可以是一个采样时刻，也可以是一个短片段。**模型处理的是你定义的序列，并不会自动知道哪个维度是时间。**

例如，假设 EEG 采样率为 256 Hz，2 秒有 512 个时刻、19 个通道：原始输入可以整理成 `(B, 512, 19)`，再用线性层把 19 维投影成 D 维。采样率、窗长和通道顺序必须以实际预处理为准。

先区分两种任务：逐点预测需要输出 `(B,L,D_out)`；整窗分类通常先获得 `(B,L,D)`，再池化为 `(B,D)`，最后分类。语言生成中的因果约束，不能原封不动套到离线 EEG 分类上。

## 2. Transformer：每个位置自己去找相关历史

自注意力把输入投影成 Q、K、V。可把 Q 理解为“我在找什么”，K 是“我有什么特征”，V 是“我能提供什么信息”。单头核心计算为：

```text
Q = X Wq, K = X Wk, V = X Wv
Attention(Q,K,V) = softmax(Q Kᵀ / sqrt(d_k) + mask) V
```

softmax 按每个查询所对应的键归一化。因果 mask 屏蔽未来位置；非因果编码器可以利用两侧信息。位置编码提供顺序信息，多头机制提供多个匹配空间，前馈层则继续加工每个位置的表示。标准模块还包括残差连接和归一化。[依据：Transformer 原论文](https://arxiv.org/abs/1706.03762)。

**手算练习：** 某个查询与三个键的归一化权重为 `(0.1,0.2,0.7)`，对应 V 为 `(1,3,5)`，则输出为 `0.1×1+0.2×3+0.7×5=4.2`。它不是简单取最近位置，而是按匹配分配信息。

标准稠密注意力要考虑 L×L 个位置对，固定宽度下计算量随 L 近似平方增长。训练时同一层的不同位置可以并行，但不同层仍有依赖。自回归生成则要等前一个 token 才能生成下一个。

需要纠正一种常见简化：**有 KV cache 时，不必为每一步重新计算全部历史 K、V。** 新查询仍要读取已有键值；缓存占用随历史增长。高效注意力实现也能避免显式保存完整注意力矩阵，因此“二次计算量”和“必须存 L×L 矩阵”应分开理解。

## 3. RNN：把历史压进一个状态

```text
h_t = tanh(W_h h_(t-1) + W_x x_t + b)
```

h_t 像一本不断改写的摘要。它用固定大小状态处理不断到来的输入，不必保存每个历史位置的键值。但摘要容量有限，长距离训练还可能遇到梯度问题。LSTM、GRU 用门控改善更新方式，并不意味着所有历史都能无损保留。

普通非线性 RNN 中，当前状态依赖上一状态的非线性结果，难以沿时间轴直接并行。接下来要问的是：能不能设计一种更有结构的状态更新，让训练也能有效并行？

## 4. SSM：把“记忆怎样变化”写成动力系统

SSM 是状态空间模型的缩写。先看连续时间的线性模型：

```text
dh(t)/dt = A h(t) + B x(t)
y(t)     = C h(t) + D_skip x(t)
```

h 是内部状态；A 描述状态自身的变化，B 把输入写入状态，C 从状态读出输出，D_skip 是输入直达输出的支路。这里用 D_skip 区别于特征维度 D。标量输入输出的教学情形下，h 为 N 维，A 为 N×N，B 为 N×1，C 为 1×N。

直观上，这是一个有 N 种记忆模式的滤波器，不是把某个脑区直接对应到一个状态。连续方程描述的是变化率，不能把 `dh/dt` 误读成下一步状态。

### 离散化：让方程能处理采样序列

采用零阶保持：在每个步长 Δ 内把输入视为常数，可得到：

```text
A_bar = exp(Δ A)
B_bar = integral from 0 to Δ of exp(s A) B ds
h_t   = A_bar h_(t-1) + B_bar x_t
y_t   = C h_t + D_skip x_t
```

exp 是矩阵指数，不是给矩阵每个元素直接取指数。若 A 可逆，B_bar 也可写为 `A⁻¹(exp(ΔA)-I)B`；积分形式没有要求 A 可逆。学习模型的 Δ 可以是可学习的内部时间尺度，**不必等于 EEG 的物理采样间隔**。

下面完全使用离散参数做练习：设 `A_bar=0.8, B_bar=0.2, C=1, D_skip=0, h_0=0`，输入依次为 `1,0,0`，状态就是 `0.2,0.16,0.128`。信息逐步衰减。若 A_bar 接近 1，记忆通常衰减更慢；若不稳定，状态可能增长失控。因此长记忆不是简单把状态维度加大。

## 5. 同一个线性 SSM，为什么又能写成卷积？

假设离散参数在每一步相同，初始状态为零。把递推展开：

```text
h_1 = B_bar x_1
h_2 = A_bar B_bar x_1 + B_bar x_2
h_3 = A_bar² B_bar x_1 + A_bar B_bar x_2 + B_bar x_3
K_j = C A_bar^j B_bar
```

于是输出是输入与因果卷积核 K 的卷积，再加直达项。这就是递推形式和卷积形式的联系：前者适合流式逐步更新，后者可以对整段序列并行计算。长卷积常借助 FFT，不能笼统说所有实现都是严格 O(L)。非零初始状态还会额外贡献状态响应项。

这里的关键前提是**线性时不变（LTI）**：同一组参数用于所有时刻。参数在训练中可以更新，“时不变”指一次序列计算时沿时间不变，不是永远不训练。

## 6. HiPPO 与 S4：解决怎样有效组织长期记忆

HiPPO 可以理解为：不用把历史逐点存下来，而是用一组多项式基的系数近似历史函数。类似用少量频谱系数概括信号，系数是压缩表示，存在近似误差，并非无限容量。

S4 将有结构的状态空间参数化、长期记忆设计和高效核计算结合起来。原始 S4 对 A 使用结构化处理，包括低秩校正等技术，以便有效计算长卷积。先掌握“递推为什么等价于卷积”，再研究结构化矩阵与数值算法，学习顺序会更顺畅。[依据：S4 原论文](https://arxiv.org/abs/2111.00396)。

## 7. Mamba：同一个输入，决定怎么写、怎么读、更新多快

固定滤波规则适合一些信号结构，但遇到“只记住被标记的符号，忽略中间干扰”等内容相关任务时，规则需要随输入变化。原始 Mamba 的选择性 SSM 让 B、C、Δ 由当前输入生成；连续参数 A 仍是共享的可学习参数，但离散 A_bar 会因 Δ 改变。它的核心和硬件实现见 [Mamba 论文第 3 节](https://arxiv.org/html/2312.00752v2#S3)。

```text
B_t = f_B(x_t)             # 怎样写入
C_t = f_C(x_t)             # 怎样读出
Δ_t = softplus(f_Δ(x_t))   # 正的内部步长
h_t = A_bar_t h_(t-1) + B_bar_t x_t
```

这只是帮助理解的机制表达，不是可直接替代官方模块的完整实现；实际存在通道扩展、参数共享与专门的离散化计算。

用稳定标量 `A=-1` 理解步长：`A_bar_t=exp(-Δ_t)`。Δ 为 0.1 时旧状态保留系数约 0.905；Δ 为 2 时约 0.135。更大的 Δ 会更快削弱旧状态，但新信息写入还受 B_t 等因素影响，不能简化成“步长越大越重要”。

**思考：** 一个大幅度 EEG 波峰可能是有效活动，也可能是眼动或肌电。选择机制由训练目标学习，既不自动去伪迹，也不能保证选择到疾病相关信号。

## 8. 参数变化了，为什么还能并行扫描？

普通固定卷积核不能直接表示输入相关的递推，但仿射状态变换仍可组合。把一步写成 `f_t(h)=a_t h+b_t`，两步合起来：

```text
f_2(f_1(h)) = (a_2 a_1) h + (a_2 b_1 + b_2)
(a_2,b_2) ∘ (a_1,b_1) = (a_2 a_1, a_2 b_1+b_2)
```

**结合律允许重新加括号，不允许交换时间顺序。** 并行前缀扫描按块组合这些变换，获得各位置状态。对于合适的结构化运算，扫描可保持线性总工作量，并以树形组合减少依赖深度；实际耗时还由访存与硬件决定。

手算校验：`f_1(h)=2h+1`、`f_2(h)=3h+4`，组合是 `6h+7`。若交换顺序会得到 `6h+9`，因此“并行”绝不是乱序读取序列。

## 9. 完整 Mamba block 与硬件优化

可按下面的简图理解原始模块；这是教学简图，具体顺序与形状以官方实现为准：

```text
输入 → 归一化 → 线性投影 ┬→ 短因果深度卷积 → SiLU → 选择性 SSM ┐
                       └→ 门控分支 → SiLU ──────────────── ×
                                              → 输出投影 → 与输入残差相加
```

短卷积提供局部混合，SSM 处理状态传播，门控调制输出。SSM 是模块的一部分，不是整个 Mamba 网络。EEG 分类还要加池化和分类头，不能把语言模型最后的 token softmax 当作所有任务的固定组件。

并行扫描解决计算依赖，硬件感知实现解决“数据搬运太贵”。融合离散化、扫描和读出，减少庞大中间状态反复写入 GPU 显存；反向传播中重算部分状态，以计算换访存。纯 Python 循环适合理解，却不能据此代表优化 Mamba 的速度。参考 [官方实现](https://github.com/state-spaces/mamba)。

## 10. 三个必须带走的边界

1. **固定大小状态不等于无限记忆。** 可以继续接收输入，不代表任意久远细节都可准确找回。
2. **线性复杂度不等于在任何设置下更快或更准。** 固定宽度和状态规模时随长度的增长趋势，与设备上的真实时间是两件事。
3. **HiPPO 是重要背景，不是所有 Mamba 都必须照搬的初始化。** 原始 Mamba 论文讨论了实值对角参数化和不同初始化，不能把 S4 的具体矩阵构造当成 Mamba 的必备定义。

| 模型 | 处理历史的主要方式 | 本组学习时应关注 |
| --- | --- | --- |
| Transformer | 当前查询读取历史位置的键值 | 注意力、位置、mask、缓存 |
| 普通 RNN | 非线性递推压缩状态 | 门控、梯度、时间依赖 |
| 线性时不变 SSM / S4 | 固定规则状态更新，可转卷积 | 离散化、核、稳定性 |
| 原始 Mamba | 输入相关地更新和读取状态 | B、C、Δ、扫描、访存 |

这条路线是理解机制的路径，不是性能排名，也不表示后出现的架构必然替代前者。

## 11. 面向我们的 EEG 项目：怎样把预习变成实验

下面是待验证的方案，不是上述文章已经证明的 EEG 结论。

**先建立可重复的基线。** 固定被试级划分、预处理和随机种子；同一被试的片段不能跨训练集与测试集。标准化、特征选择、调参等仅使用训练部分拟合；若存在批次信息，增加跨批次评估。模型更换不应掩盖数据问题。

**先用相同输入比较。** 在相同片段上比较 EEGNet、Transformer 和 Mamba，记录被试级指标、参数量、训练时间、峰值显存及实际序列长度。2 秒短窗上是否有优势应实测；延长输入后同时检查样本组织和任务是否改变，不把输入更多的收益归功于架构。

**双向结构是可选实验。** 离线分类可分别正向、反向编码，把反向输出恢复原时间顺序后融合，再池化分类。这是本组可以探索的 Bi-Mamba 方案，不属于原始因果 Mamba 的自动功能；严格在线预测不能使用尚未到来的数据。双向也不是 Mamba 独占的能力。

**做消融而非只换名字。** 对照单向与双向、固定参数 SSM 与选择性 SSM、不同窗长和相近参数预算。报告多随机种子结果和被试级不确定性。若样本有限、结果不稳，就明确写出，不推断为诊断能力。

## 12. 四次组内预习安排与验收

1. **注意力与状态：** 每人画出 `(B,L,D)` 到分类输出的形状；手算一次注意力。验收：能解释训练并行与自回归生成串行的区别。
2. **递推与卷积：** 用一维状态写循环，再用展开的核计算相同输出。验收：零初态时两种计算误差接近浮点精度，并解释非零初态差在哪。
3. **选择与扫描：** 手算上述仿射变换，比较两种 Δ；再实现输入生成 B、C、Δ 的教学递推。验收：能说明结合律与交换律的区别，不声称教学代码等同完整 Mamba。
4. **EEG 小规模对照：** 先在固定分组的开发集跑通一个批次和完整训练流程，登记形状、参数与资源用量。验收：所有模型沿用相同评估协议，测试集不参与选择模型。

自测问题：为什么固定 SSM 可以转卷积？为什么选择性模型通常不能用同一个固定核？为什么连续 A 不变而 A_bar_t 可以变化？为什么模型接收更长输入不等于记住所有输入？为什么双向编码不能直接用于严格实时系统？能不用背术语解释这五题，就具备继续阅读论文和实现的基础。
